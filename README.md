#### 🧩 Omarchy plugins
Install any of them with `omarchy plugin add <repo-url> --enable`. The whole set lives in **[omarchy-plugins](https://github.com/gusthanks/omarchy-plugins)**.

| Plugin | What it does |
|---|---|
| [Agents Pet](https://github.com/gusthanks/omarchy-agents-pet) | A pet you design, living in your bar: follows your cursor, worries when an AI limit is close |
| [Weather Plus](https://github.com/gusthanks/omarchy-weather) | Rain forecast, hourly strip, UV, sunrise/sunset and a radar link |
| [Calendar for Google](https://github.com/gusthanks/omarchy-google-calendar) | Google Calendar sync with Day, Week, Month and Year views |
| [Resource Monitor](https://github.com/gusthanks/omarchy-resources) | CPU, memory, disks, sensors, processes and background file transfers |
| [Drive for Google](https://github.com/gusthanks/omarchy-gdrive) | Your own OAuth client, an rclone mount that survives reboots, a `doctor` command |
